# KDAG Blog Frontend Clone

A responsive frontend recreation of the Kharagpur Data Analytics Group (KDAG) blog page built using React. This project replicates the layout, blog listing system, filtering experience, and modern dark-themed UI while focusing on component reusability and clean frontend architecture.

## Overview

This project recreates the KDAG blog webpage interface with emphasis on:

- Component-based React architecture
- Dynamic blog rendering using JSON data
- Tag-based filtering system
- Search functionality
- Responsive dark-themed UI
- Reusable and maintainable code structure

The aim was to strengthen frontend development skills by implementing a real-world interface and reproducing user interactions.
